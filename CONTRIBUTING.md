# Contributing to SAFE

Thank you for considering a contribution.

## Constitutional Filter
Every PR, issue, and design proposal is evaluated against:
1. Civilisational continuation
2. Planetary restoration
3. Abundance for future generations

Contributions that systematically trade long-term epistemic integrity for short-term narrative comfort, institutional capture, or opacity will be declined.

## Principles
- Prefer machine-readable, versioned artefacts over prose.
- Never let ethical desirability alter factual scores.
- Surface uncertainty and contradiction rather than suppress them.
- Keep the core engine vendor-neutral.

## Process
1. Open an issue describing the change and the constitutional rationale.
2. Fork → branch → PR.
3. All schema changes must update the corresponding JSON Schema and any dependent code.
4. Scoring changes require a sensitivity analysis note.
